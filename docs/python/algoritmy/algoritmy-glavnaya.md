## Как заниматься {#kak-zanimatsya}

Для каждой темы используй один порядок:

1. Прочитай объяснение.
2. Запусти примеры самостоятельно.
3. До запуска назови ожидаемый результат и сложность.
4. Измени входные данные и проверь предположение.
5. Реши задачи без подсказок.
6. Запиши ошибки и повтори сложные задачи через неделю.
