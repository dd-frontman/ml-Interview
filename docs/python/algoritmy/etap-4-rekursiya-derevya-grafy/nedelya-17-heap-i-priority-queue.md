## Цель недели {#tsel-nedeli}

Научиться использовать частичный порядок, когда полный отсортированный список не нужен, а важен быстрый доступ к элементу с наивысшим приоритетом.

После недели нужно уметь:

- объяснить инвариант min-heap;
- находить родителя и детей узла в массиве;
- использовать `heapify`, `heappush` и `heappop`;
- отличать кучу от отсортированного списка;
- моделировать max-heap через отрицательные значения;
- решать задачи Top K;
- хранить составной приоритет в кортеже;
- объединять несколько отсортированных последовательностей;
- выбирать между кучей и сортировкой.

## Что такое куча {#chto-takoe-kucha}

Куча, или heap, — структура данных с частичным порядком.

В **min-heap** выполняется инвариант:

```text
значение родителя <= значений его детей
```

Поэтому минимальный элемент всегда находится в корне.

Важное ограничение: остальные элементы не обязаны идти по возрастанию.

Например, список:

```python
heap = [1, 4, 2, 9, 7, 5]
```

может быть корректной min-heap, хотя `4` стоит перед `2`.

## Куча хранится в списке {#kucha-khranitsya-v-spiske}

Бинарное дерево можно разместить в массиве по уровням:

```text
        1
      /   \
     4     2
    / \   /
   9   7 5
```

```text
индексы: 0  1  2  3  4  5
значения: 1  4  2  9  7  5
```

Для узла с индексом `index`:

```python
parent = (index - 1) // 2
left_child = 2 * index + 1
right_child = 2 * index + 2
```

Отдельные объекты узлов и ссылки не нужны.

## Почему операции занимают O(log n) {#pochemu-operatsii-zanimayut-o-log-n}

Куча является почти полным бинарным деревом. Ее высота равна `O(log n)`.

При добавлении элемент:

1. Помещается в конец списка.
2. Поднимается к родителю, пока инвариант нарушен.

При удалении минимума:

1. Корень заменяется последним элементом.
2. Новый корень опускается к меньшему ребенку.

Перемещение проходит не более высоты дерева, поэтому `push` и `pop` работают за `O(log n)`.

## Основные операции heapq {#osnovnye-operatsii-heapq}

Модуль `heapq` работает с обычным списком:

```python
import heapq


numbers = [7, 2, 5, 1, 9]
heapq.heapify(numbers)

minimum = numbers[0]  # Минимум равен 1, но не удаляется.

heapq.heappush(numbers, 3)
removed = heapq.heappop(numbers)  # Удаляется текущий минимум 1.
```

| Операция | Сложность |
| --- | --- |
| `heap[0]` | `O(1)` |
| `heappush()` | `O(log n)` |
| `heappop()` | `O(log n)` |
| `heapify()` | `O(n)` |
| `heappushpop()` | `O(log n)` |
| `heapreplace()` | `O(log n)` |

`heapify()` преобразует существующий список на месте. После этого исходный порядок списка изменяется.

## Почему heapify работает за O(n) {#pochemu-heapify-rabotaet-za-o-n}

Если добавлять `n` элементов по одному, верхняя оценка будет `O(n log n)`.

`heapify()` начинает с нижних внутренних узлов. Большинство узлов находится близко к листьям и опускается на очень небольшое расстояние. Суммарная работа по всем уровням равна `O(n)`.

Не обязательно выводить формулу на собеседовании, но важно знать, что `heapify()` эффективнее последовательных `heappush()` для уже готового массива.

## Куча не является сортировкой {#kucha-ne-yavlyaetsya-sortirovkoy}

Корректно:

```python
minimum = heap[0]
```

Некорректно ожидать:

```python
second_minimum = heap[1]
```

На индексах `1` и `2` находятся дети корня, но меньший из них заранее не гарантирован конкретной позицией.

Чтобы извлечь элементы по порядку, нужно последовательно вызывать `heappop()`. Это разрушает кучу и занимает `O(n log n)`.

## Пример 1. Последний камень {#primer-1-posledniy-kamen}

На каждом шаге берутся два самых тяжелых камня. `heapq` предоставляет min-heap, поэтому для максимума сохраним отрицательные веса.

```python
import heapq


def last_stone_weight(stones: list[int]) -> int:
    # Отрицательное самого большого веса является минимальным числом.
    max_heap = [-weight for weight in stones]
    heapq.heapify(max_heap)

    while len(max_heap) > 1:
        first = -heapq.heappop(max_heap)
        second = -heapq.heappop(max_heap)

        if first != second:
            difference = first - second
            heapq.heappush(max_heap, -difference)

    if not max_heap:
        return 0

    return -max_heap[0]
```

### Почему знак меняется дважды {#pochemu-znak-menyaetsya-dvazhdy}

При добавлении:

```text
вес 10 -> в куче -10
вес 4  -> в куче -4
```

Min-heap выберет `-10`, потому что это меньше `-4`. После извлечения знак возвращается обратно.

Важно не смешивать положительные и отрицательные значения в одной куче.

Если камней `n`, выполняется до `n - 1` итераций:

- `heapify`: `O(n)`;
- цикл: `O(n log n)`;
- память: `O(n)`.

## Top K: какую кучу выбрать {#top-k-kakuyu-kuchu-vybrat}

Если нужно сохранить `k` самых больших элементов, удобно использовать min-heap размера `k`.

Почему min-heap:

- корень — самый маленький среди выбранных больших элементов;
- новый элемент сравнивается именно с этой границей;
- если новый больше корня, корень удаляется.

В куче остаются `k` лучших кандидатов, а самый слабый из них всегда доступен за `O(1)`.

## Пример 2. K-й наибольший элемент {#primer-2-k-y-naibolshiy-element}

```python
import heapq


def find_kth_largest(numbers: list[int], k: int) -> int:
    if not 1 <= k <= len(numbers):
        raise ValueError("k должен находиться в границах списка")

    heap: list[int] = []

    for number in numbers:
        heapq.heappush(heap, number)

        if len(heap) > k:
            # Удаляем минимальный элемент среди кандидатов.
            heapq.heappop(heap)

    # В куче находятся k наибольших значений.
    # Минимальное из них и есть k-е наибольшее.
    return heap[0]
```

Для `[3, 2, 1, 5, 6, 4]` и `k = 2` в конце останутся `[5, 6]`, а корень `5` будет вторым наибольшим.

- время: `O(n log k)`;
- память: `O(k)`.

Полная сортировка заняла бы `O(n log n)`. При маленьком `k` куча выгоднее.

## heappushpop и heapreplace {#heappushpop-i-heapreplace}

Обе функции объединяют добавление и удаление, но порядок различается.

`heappushpop(heap, value)`:

1. Добавляет значение.
2. Удаляет минимальное из обновленной кучи.

`heapreplace(heap, value)`:

1. Сначала удаляет текущий минимум.
2. Затем добавляет новое значение.

Для Top K можно использовать:

```python
if number > heap[0]:
    heapq.heapreplace(heap, number)
```

Проверка гарантирует, что новый кандидат действительно лучше текущей границы.

## Приоритетная очередь {#prioritetnaya-ochered}

Обычная очередь обрабатывает элементы по времени поступления. Приоритетная очередь — по приоритету.

В `heapq` можно хранить кортежи:

```python
(priority, value)
```

Кортежи сравниваются слева направо. Сначала сравнивается `priority`, а при равенстве — `value`.

## Проблема равных приоритетов {#problema-ravnykh-prioritetov}

Пусть объекты задач не поддерживают сравнение:

```python
class Task:
    def __init__(self, name: str) -> None:
        self.name = name
```

Если положить `(1, task_a)` и `(1, task_b)`, Python попытается сравнить объекты `Task` после равенства приоритетов и получит `TypeError`.

Добавляется уникальный порядковый номер:

```python
(priority, order, task)
```

## Пример 3. Очередь задач с одинаковым приоритетом {#primer-3-ochered-zadach-s-odinakovym-prioritetom}

```python
import heapq
from itertools import count


def order_tasks(tasks: list[tuple[int, str]]) -> list[str]:
    heap: list[tuple[int, int, str]] = []
    order = count()

    for priority, task_name in tasks:
        heapq.heappush(
            heap,
            (priority, next(order), task_name),
        )

    result: list[str] = []

    while heap:
        _, _, task_name = heapq.heappop(heap)
        result.append(task_name)

    return result
```

Меньшее значение `priority` обрабатывается первым. При равных приоритетах счетчик сохраняет порядок поступления.

Если большее число означает более высокий приоритет, его можно хранить со знаком минус.

## Пример 4. K ближайших точек {#primer-4-k-blizhayshikh-tochek}

Нужно вернуть `k` точек, ближайших к началу координат.

Квадрат расстояния:

```text
x² + y²
```

Корень вычислять не нужно: квадратный корень сохраняет порядок расстояний.

```python
import heapq


def k_closest(
    points: list[tuple[int, int]],
    k: int,
) -> list[tuple[int, int]]:
    heap: list[tuple[int, int, int]] = []

    for x, y in points:
        distance_squared = x * x + y * y
        heapq.heappush(heap, (distance_squared, x, y))

    result: list[tuple[int, int]] = []

    for _ in range(min(k, len(heap))):
        _, x, y = heapq.heappop(heap)
        result.append((x, y))

    return result
```

Этот вариант строит кучу из всех точек:

- время: `O(n + k log n)`;
- память: `O(n)`.

Альтернатива — поддерживать max-heap размера `k`, что дает `O(n log k)` времени и `O(k)` памяти.

## Слияние отсортированных последовательностей {#sliyanie-otsortirovannykh-posledovatelnostey}

Если есть `k` отсортированных списков, в куче достаточно хранить только первый еще не использованный элемент каждого списка.

После извлечения элемента в кучу добавляется следующий элемент из того же списка.

## Пример 5. Merge K Sorted Lists {#primer-5-merge-k-sorted-lists}

Здесь объединяются обычные списки чисел, чтобы сосредоточиться на работе кучи.

```python
import heapq


def merge_sorted_lists(lists: list[list[int]]) -> list[int]:
    heap: list[tuple[int, int, int]] = []

    for list_index, numbers in enumerate(lists):
        if numbers:
            # Храним значение, номер списка и индекс внутри списка.
            heapq.heappush(heap, (numbers[0], list_index, 0))

    result: list[int] = []

    while heap:
        value, list_index, element_index = heapq.heappop(heap)
        result.append(value)

        next_index = element_index + 1
        source_list = lists[list_index]

        if next_index < len(source_list):
            heapq.heappush(
                heap,
                (source_list[next_index], list_index, next_index),
            )

    return result
```

В куче находится не более `k` элементов.

Если общее количество чисел равно `n`:

- время: `O(n log k)`;
- память кучи: `O(k)`;
- память результата: `O(n)`.

## Куча или сортировка {#kucha-ili-sortirovka}

Используй сортировку, когда:

- нужен полный порядок всех элементов;
- данные уже целиком находятся в памяти;
- после сортировки выполняется много запросов по позициям.

Используй кучу, когда:

- нужен только минимум или максимум;
- данные поступают постепенно;
- нужно хранить `k` лучших элементов;
- приоритеты меняют порядок обработки;
- объединяются несколько отсортированных потоков.

## Куча или deque {#kucha-ili-deque}

`deque` выбирает самый старый элемент за `O(1)`. Heap выбирает элемент с минимальным приоритетом за `O(log n)`.

| Структура | Кто выходит первым |
| --- | --- |
| Queue / deque | Кто раньше пришел |
| Priority Queue / heap | У кого выше приоритет |

Если приоритет не нужен, обычная очередь проще и быстрее.

## Частые ошибки {#chastye-oshibki}

1. Считать внутренний список кучи полностью отсортированным.
2. Читать второй минимум как `heap[1]`.
3. Вызвать `heappop()` у пустой кучи.
4. Забыть вернуть знак после извлечения из max-heap.
5. Смешать положительные и отрицательные приоритеты.
6. Хранить несравнимые объекты после одинакового приоритета.
7. Поддерживать кучу размера `n`, когда достаточно размера `k`.
8. Полностью сортировать данные для одного минимума.
9. Забыть, что `heapify()` изменяет список на месте.
10. Перепутать семантику `heappushpop()` и `heapreplace()`.

## План занятий {#plan-zanyatiy}

1. Нарисуй дерево для списка-кучи и вычисли индексы детей.
2. Выполни `heapify`, `push` и `pop` вручную.
3. Реализуй max-heap через отрицательные значения.
4. Реши задачу про последний камень.
5. Поддерживай Top K кучей фиксированного размера.
6. Добавь порядковый номер в приоритетную очередь.
7. Объедини несколько отсортированных списков.
8. Для каждой задачи сравни кучу с полной сортировкой.

## Задачи для самостоятельного решения {#zadachi-dlya-samostoyatelnogo-resheniya}

### Задача 1. K-й наибольший элемент в потоке {#zadacha-1-k-y-naibolshiy-element-v-potoke}

Реализуй класс, который получает `k` и начальный список чисел. Метод `add(value)` должен добавлять новое число и возвращать текущий `k`-й наибольший элемент.

Требования:

- не сортировать все накопленные числа после каждого добавления;
- хранить только необходимые кандидаты;
- выполнять одно добавление за `O(log k)`;
- объяснить, почему корень является ответом.

### Задача 2. Median Finder {#zadacha-2-median-finder}

Реализуй структуру с операциями:

- `add_num(value)`;
- `find_median()`.

Используй две кучи:

- max-heap для меньшей половины;
- min-heap для большей половины.

Поддерживай два инварианта:

1. Все значения левой половины не больше значений правой.
2. Размеры куч отличаются не более чем на один элемент.

Объясни отдельно вычисление медианы для четного и нечетного количества чисел.
