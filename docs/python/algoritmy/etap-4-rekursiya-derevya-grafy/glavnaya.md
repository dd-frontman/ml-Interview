## Неделя 12. Recursion {#nedelya-12-recursion}

Рекурсивная функция вызывает саму себя с более простой версией задачи.

В каждой реализации должны быть:

1. **Базовый случай**, который завершает рекурсию.
2. **Рекурсивный переход**, который приближает вход к базовому случаю.
3. **Возврат результата**, если вычисления должны собраться обратно по стеку.

### Что изучить {#chto-izuchit}

- стек вызовов;
- локальные переменные каждого вызова;
- глубину рекурсии;
- divide and conquer;
- повторяющиеся вычисления;
- memoization;
- преобразование рекурсии в явный стек.

В Python нет оптимизации хвостовой рекурсии. Для очень глубокого входа итеративное решение может быть безопаснее.

### Практика {#praktika}

- факториал;
- сумма списка по индексу;
- `Pow(x, n)`;
- рекурсивный Binary Search;
- Merge Sort;
- Fibonacci сначала без кэша, затем с мемоизацией.

### Частые ошибки {#chastye-oshibki}

- отсутствие базового случая;
- вход не приближается к завершению;
- потеря `return` перед рекурсивным вызовом;
- срез на каждом вызове и лишняя память;
- игнорирование памяти стека.

## Неделя 13. Binary Trees {#nedelya-13-binary-trees}

Узел бинарного дерева содержит значение и не более двух потомков.

```python
class TreeNode:
    def __init__(
        self,
        value: int,
        left: "TreeNode | None" = None,
        right: "TreeNode | None" = None,
    ) -> None:
        self.value = value
        self.left = left
        self.right = right
```

### Виды обхода DFS {#vidy-obkhoda-dfs}

- preorder: узел, левое поддерево, правое поддерево;
- inorder: левое поддерево, узел, правое поддерево;
- postorder: левое поддерево, правое поддерево, узел.

Порядок выбирается по моменту обработки текущего узла.

### BFS по уровням {#bfs-po-urovnyam}

Для обхода по уровням используется очередь. Все узлы текущего уровня обрабатываются до перехода к следующему.

### Что изучить {#chto-izuchit-2}

- высоту и глубину;
- количество узлов;
- диаметр дерева;
- сравнение деревьев;
- инвертирование;
- свойства Binary Search Tree;
- рекурсивный и итеративный DFS;
- level-order traversal.

### Практика {#praktika-2}

- `Maximum Depth of Binary Tree`;
- `Invert Binary Tree`;
- `Same Tree`;
- `Diameter of Binary Tree`;
- `Binary Tree Level Order Traversal`;
- `Validate Binary Search Tree`.

### Частые ошибки {#chastye-oshibki-2}

- не обработать пустое дерево;
- путать высоту узла с количеством ребер или узлов;
- проверять BST только относительно непосредственного родителя;
- вычислять один и тот же результат поддерева несколько раз;
- забыть, что рекурсивный DFS использует память стека.

## Неделя 14. Матрицы и Grid Traversal {#nedelya-14-matritsy-i-grid-traversal}

Матрицу удобно рассматривать как граф: каждая клетка является вершиной, а допустимые переходы - ребрами.

Для четырех направлений можно хранить смещения:

```python
directions = ((1, 0), (-1, 0), (0, 1), (0, -1))
```

### Что изучить {#chto-izuchit-3}

- координаты `(row, column)`;
- проверку границ;
- DFS и BFS по клеткам;
- `visited` как множество кортежей;
- изменение матрицы на месте вместо отдельного `visited`;
- компоненты связности;
- кратчайший путь в невзвешенной сетке.

### Практика {#praktika-3}

- `Flood Fill`;
- `Number of Islands`;
- `Max Area of Island`;
- `Rotting Oranges`;
- `Pacific Atlantic Water Flow`.

### Частые ошибки {#chastye-oshibki-3}

- перепутать строки и столбцы;
- проверить значение до проверки границ;
- добавить клетку в `visited` слишком поздно и обработать ее несколько раз;
- использовать DFS для кратчайшего пути без дополнительной логики;
- случайно изменить вход, хотя это запрещено.

## Неделя 15. Graphs {#nedelya-15-graphs}

Граф состоит из вершин и ребер.

### Представления {#predstavleniya}

**Adjacency list** хранит список соседей каждой вершины. Память обычно `O(V + E)`.

**Adjacency matrix** хранит связь каждой пары вершин. Память `O(V²)`.

Для разреженных графов обычно удобнее adjacency list.

### Что изучить {#chto-izuchit-4}

- directed и undirected graph;
- DFS и BFS;
- множество посещенных вершин;
- компоненты связности;
- поиск пути;
- обнаружение цикла;
- состояния `unvisited`, `visiting`, `visited` для ориентированного графа;
- сложность `O(V + E)`.

### Практика {#praktika-4}

- `Find if Path Exists in Graph`;
- `Clone Graph`;
- `Number of Provinces`;
- `Course Schedule`;
- подсчет компонентов связности.

### Частые ошибки {#chastye-oshibki-4}

- не добавить вершину в `visited` до обхода соседей;
- забыть пройти все вершины несвязного графа;
- дважды добавить ребро в ориентированном графе;
- использовать только `visited`, когда для цикла нужны три состояния;
- назвать сложность `O(V)`, забыв про ребра.

## Неделя 16. Backtracking {#nedelya-16-backtracking}

Backtracking рассматривает задачу как дерево решений:

```text
choose -> explore -> unchoose
```

### Состояние решения {#sostoyanie-resheniya}

Нужно определить:

- какие варианты доступны на текущем шаге;
- что уже находится в текущем пути;
- когда получен полный ответ;
- когда ветку можно остановить;
- какое изменение нужно отменить после рекурсивного вызова.

### Копирование результата {#kopirovanie-rezultata}

Если текущий путь изменяется на месте, в итоговый список добавляется его копия. Иначе все ответы могут ссылаться на один изменяемый объект.

### Практика {#praktika-5}

- `Subsets`;
- `Permutations`;
- `Combination Sum`;
- `Letter Combinations of a Phone Number`;
- `Generate Parentheses`.

### Частые ошибки {#chastye-oshibki-5}

- забыть отменить выбор;
- добавить в результат исходный изменяемый список вместо копии;
- неверно выбрать условие завершения;
- генерировать заведомо недопустимые ветви вместо pruning;
- заменять первую реализацию вызовом `itertools.permutations()`.

## Неделя 17. Heap и Priority Queue {#nedelya-17-heap-i-priority-queue}

Куча хранит частичный порядок. В min-heap минимальный элемент всегда находится в корне, но остальные элементы не обязаны быть полностью отсортированы.

### Что изучить {#chto-izuchit-5}

- heap invariant;
- `heapify()`;
- `heappush()` и `heappop()`;
- получение минимума через `heap[0]`;
- Top K;
- объединение отсортированных последовательностей;
- приоритетную очередь с кортежем `(priority, order, value)`;
- max-heap через отрицательный приоритет для совместимости со старыми версиями Python.

### Когда heap лучше сортировки {#kogda-heap-luchshe-sortirovki}

Куча полезна, если:

- данные поступают постепенно;
- нужен только минимум или максимум;
- требуется сохранить `k` лучших элементов;
- не нужен полный порядок всех значений.

### Практика {#praktika-6}

- `Last Stone Weight`;
- `Kth Largest Element in an Array`;
- `K Closest Points to Origin`;
- `Task Scheduler`;
- `Merge K Sorted Lists`.

### Частые ошибки {#chastye-oshibki-6}

- ожидать, что список-куча полностью отсортирован;
- забыть инвертировать знак при моделировании max-heap;
- положить в кучу кортежи с равным приоритетом и несравнимыми объектами;
- сортировать все данные, когда нужен только небольшой Top K.

## Разобранные примеры {#razobrannye-primery}

### Рекурсивный DFS: максимальная глубина дерева {#rekursivnyy-dfs-maksimalnaya-glubina-dereva}

```python
def max_depth(root: "TreeNode | None") -> int:
    if root is None:
        # Пустое поддерево не добавляет уровней.
        return 0

    # Каждый вызов полностью вычисляет глубину своего поддерева.
    left_depth = max_depth(root.left)
    right_depth = max_depth(root.right)

    # Текущий узел добавляет один уровень к более глубокому поддереву.
    return 1 + max(left_depth, right_depth)
```

Каждый узел посещается один раз.

- Время: `O(n)`, где `n` - количество узлов.
- Память: `O(h)` для стека, где `h` - высота дерева.

Для вырожденного дерева `h = n`, для сбалансированного `h = log n`.

### BFS: расстояния от начальной вершины {#bfs-rasstoyaniya-ot-nachalnoy-vershiny}

```python
from collections import deque


def shortest_distances(
    graph: dict[str, list[str]],
    start: str,
) -> dict[str, int]:
    queue = deque([start])
    distances = {start: 0}

    while queue:
        vertex = queue.popleft()

        for neighbor in graph.get(vertex, []):
            if neighbor in distances:
                # Вершина уже посещена по кратчайшему пути.
                continue

            # Сосед находится на один переход дальше текущей вершины.
            distances[neighbor] = distances[vertex] + 1

            # Добавляем вершину после отметки, чтобы не поставить ее повторно.
            queue.append(neighbor)

    return distances
```

BFS подходит, потому что все ребра имеют одинаковую стоимость. Взвешенный граф потребовал бы другой алгоритм.

- Время: `O(V + E)`.
- Память: `O(V)`.

### Backtracking: все подмножества {#backtracking-vse-podmnozhestva}

```python
def subsets(numbers: list[int]) -> list[list[int]]:
    result: list[list[int]] = []
    current: list[int] = []

    def backtrack(start: int) -> None:
        # Добавляем копию: current будет изменяться после возврата.
        result.append(current.copy())

        for index in range(start, len(numbers)):
            current.append(numbers[index])  # choose
            backtrack(index + 1)  # explore
            current.pop()  # unchoose: возвращаем прежнее состояние

    backtrack(0)
    return result
```

Для `n` различных элементов существует `2ⁿ` подмножеств, поэтому экспоненциальное время здесь определяется размером самого ответа.

## Порядок освоения обходов {#poryadok-osvoeniya-obkhodov}

Для каждой новой структуры используй одинаковую последовательность:

1. Нарисуй небольшой пример.
2. Определи вершины и допустимые переходы.
3. Выбери DFS или BFS.
4. Определи состояние `visited`.
5. Назови условие завершения.
6. Оцени количество посещенных вершин и ребер.
7. Только после этого пиши код.

## Итоговая проверка {#itogovaya-proverka}

Этап пройден, если ты можешь:

- написать рекурсивный и итеративный DFS;
- выполнить BFS с `deque`;
- обойти дерево в трех порядках;
- решить задачу на матрицу через DFS или BFS;
- представить граф списком смежности;
- объяснить `O(V + E)`;
- восстановить состояние в backtracking;
- применить heap для Top K;
- выбрать между DFS, BFS, backtracking и heap;
- пройти второе пробное интервью без критической подсказки.

## Задачи для самостоятельного решения {#zadachi-dlya-samostoyatelnogo-resheniya}

### Задача 1. Количество островов {#zadacha-1-kolichestvo-ostrovov}

Дана матрица из символов `"1"` и `"0"`. Соседними считаются клетки сверху, снизу, слева и справа. Посчитай количество отдельных островов из единиц.

Требования:

- реализуй сначала DFS, затем BFS;
- объясни, когда клетка добавляется в `visited`;
- назови сложность через количество строк и столбцов.

### Задача 2. K ближайших точек {#zadacha-2-k-blizhayshikh-tochek}

Дан список точек `(x, y)` и число `k`. Верни `k` точек, расположенных ближе всего к началу координат.

Необязательно извлекать квадратный корень: для сравнения достаточно `x² + y²`. Сравни решение через полную сортировку и решение через heap.
