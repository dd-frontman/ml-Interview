## Цель недели {#tsel-nedeli}

Познакомиться с несколькими независимыми алгоритмами и структурами, которые встречаются реже базовых паттернов, но важны для сильных алгоритмических секций.

После недели нужно уметь:

- получить порядок выполнения зависимых задач;
- объединять компоненты через Union Find;
- искать кратчайшие пути с неотрицательными весами;
- хранить и искать строки по префиксу через Trie;
- применять основные битовые операции;
- выбирать инструмент по ограничениям задачи, а не только по знакомым словам.

## Карта недели {#karta-nedeli}

| Тема | Какая задача решается |
| --- | --- |
| [Topological Sort](./topological-sort.md) | порядок выполнения зависимостей и поиск циклов в DAG |
| [Union Find](./union-find.md) | динамическое объединение компонентов и проверка связности |
| [Dijkstra](./dijkstra.md) | кратчайшие пути в графе с неотрицательными весами |
| [Trie](./trie.md) | хранение строк и быстрый поиск по префиксу |
| [Битовые операции](./bitovye-operatsii.md) | работа с флагами, XOR и компактным представлением подмножеств |
| [Практика](./praktika.md) | выбор структуры, частые ошибки, план занятий и задачи |

## Как проходить эту неделю {#kak-prokhodit-etu-nedelyu}

Темы слабо связаны между собой. Не нужно пытаться освоить их за один день.

Рекомендуемый порядок:

1. Повтори Topological Sort после недели графов.
2. Разбери Union Find и компоненты.
3. Свяжи Dijkstra с priority queue.
4. Реализуй Trie как новую структуру данных.
5. Заверши битовыми операциями.
6. Реши две итоговые задачи без копирования готового кода.

Если времени мало, используй такой приоритет:

```text
Topological Sort -> Union Find -> Dijkstra -> Trie -> Bits
```

Реальный приоритет зависит от формата собеседований конкретной компании. Если продвинутые темы не встречаются в требованиях, полезнее потратить время на повторение основных паттернов и смешанные Medium-задачи.

## Быстрый выбор инструмента {#bystryy-vybor-instrumenta}

| Сигнал в условии | Возможный инструмент |
| --- | --- |
| Зависимости и допустимый порядок | Topological Sort |
| Постепенное объединение групп | Union Find |
| Неотрицательные веса и кратчайшее расстояние | Dijkstra |
| Поиск слов по началу | Trie |
| Флаги, XOR, компактные подмножества | Битовые операции |

Не выбирай алгоритм только по одному слову. Например, кратчайший путь без весов проще найти через BFS, а проверку полного слова обычно проще выполнить через `set`, а не Trie.

## Критерий готовности {#kriteriy-gotovnosti}

Тема усвоена, если ты можешь:

1. объяснить, какую проблему решает структура;
2. назвать ограничения алгоритма;
3. воспроизвести минимальную реализацию;
4. оценить временную и пространственную сложность;
5. объяснить, почему более простой инструмент не подходит.
