## Неделя 9. Stack {#nedelya-9-stack}

Стек работает по правилу LIFO: последний добавленный элемент извлекается первым.

В Python обычный стек реализуется через `list`:

- `append()` добавляет элемент;
- `pop()` удаляет последний элемент;
- `stack[-1]` читает вершину.

Все эти операции выполняются за `O(1)` или амортизированно `O(1)`.

### Когда нужен стек {#kogda-nuzhen-stek}

- вложенные скобки;
- отмена операций;
- вычисление выражений;
- обход дерева или графа без рекурсии;
- необходимость вернуться к последнему незавершенному состоянию.

### Инвариант {#invariant}

В стеке должны находиться только элементы, которые еще могут повлиять на будущий ответ.

### Практика {#praktika}

- `Valid Parentheses`;
- `Min Stack`;
- `Evaluate Reverse Polish Notation`;
- итеративный DFS как подготовка к следующему этапу.

### Частые ошибки {#chastye-oshibki}

- вызвать `pop()` у пустого стека;
- сохранить значение, когда нужен индекс;
- забыть проверить, что после обработки стек пуст;
- использовать `insert(0)` и `pop(0)` вместо конца списка.

## Monotonic Stack {#monotonic-stack}

Монотонный стек хранит элементы в возрастающем или убывающем порядке. Перед добавлением нового элемента неподходящие элементы удаляются.

Он применяется для задач вида:

- следующий больший элемент;
- предыдущий меньший элемент;
- ближайший день с большей температурой;
- максимальный прямоугольник в гистограмме.

Хотя внутри цикла может находиться `while`, каждый элемент добавляется и удаляется не более одного раза. Поэтому общая сложность обычно `O(n)`, а не `O(n²)`.

### Практика {#praktika-2}

- `Daily Temperatures`;
- `Next Greater Element`;
- `Largest Rectangle in Histogram`.

Перед решением сформулируй:

1. Что хранится в стеке: значения или индексы?
2. Стек возрастает или убывает?
3. Какое условие удаляет вершину?
4. Когда найден ответ для удаляемого элемента?

## Неделя 10. Queue и Deque {#nedelya-10-queue-i-deque}

Очередь работает по правилу FIFO: первый добавленный элемент извлекается первым.

Для очереди в Python используй `collections.deque`:

- `append()` - добавить справа;
- `popleft()` - удалить слева;
- `appendleft()` - добавить слева;
- `pop()` - удалить справа.

### Когда нужна очередь {#kogda-nuzhna-ochered}

- обработка в порядке поступления;
- BFS;
- поиск кратчайшего пути в невзвешенном графе;
- обход дерева по уровням;
- моделирование очереди задач.

Не используй `list.pop(0)` для регулярного удаления слева: операция требует сдвига элементов и работает за `O(n)`.

### Монотонная очередь {#monotonnaya-ochered}

Это дополнительная тема для поиска максимума или минимума в скользящем окне. В `deque` хранятся только кандидаты, которые еще могут стать ответом.

### Практика {#praktika-3}

- реализовать очередь через `deque`;
- реализовать очередь через список и индекс `head`;
- `Number of Recent Calls`;
- `Moving Average from Data Stream`;
- `Sliding Window Maximum` как продвинутая задача.

## Неделя 11. Linked List {#nedelya-11-linked-list}

Связный список состоит из узлов. Каждый узел хранит значение и ссылку на следующий узел.

```python
class ListNode:
    def __init__(self, value: int, next_node: "ListNode | None" = None) -> None:
        self.value = value
        self.next = next_node
```

В отличие от `list`, связный список не дает быстрого доступа по индексу. Чтобы получить десятый узел, нужно пройти предыдущие девять.

### Что изучить {#chto-izuchit}

- узел и ссылку `next`;
- односвязный и двусвязный список;
- вставку и удаление после известного узла;
- dummy node;
- разворот списка;
- медленный и быстрый указатели;
- поиск середины;
- обнаружение цикла.

### Безопасное изменение ссылок {#bezopasnoe-izmenenie-ssylok}

При развороте списка нельзя потерять оставшуюся часть. Обычно перед изменением `current.next` сохраняют старую ссылку в `next_node`.

### Dummy node {#dummy-node}

Фиктивный начальный узел уменьшает количество отдельных проверок для головы списка. После обработки настоящая голова находится в `dummy.next`.

### Практика {#praktika-4}

- `Reverse Linked List`;
- `Merge Two Sorted Lists`;
- `Linked List Cycle`;
- `Middle of the Linked List`;
- `Remove Nth Node From End of List`.

### Частые ошибки {#chastye-oshibki-2}

- потерять ссылку на следующий узел;
- обратиться к `current.next`, когда `current` равен `None`;
- неверно обновить голову списка;
- сравнивать значения узлов вместо самих узлов при поиске цикла;
- ошибиться на списке из одного элемента.

## Что реализовать самостоятельно {#chto-realizovat-samostoyatelno}

До перехода дальше реализуй без библиотек:

1. Стек с `push`, `pop` и `peek`.
2. Очередь с `enqueue` и `dequeue`.
3. Односвязный список с добавлением и удалением.
4. Разворот связного списка.
5. Поиск цикла быстрым и медленным указателями.

Цель не в том, чтобы использовать самописные структуры в рабочем Python-коде. Реализация нужна для понимания операций и ссылок.

## Разобранные примеры {#razobrannye-primery}

### Стек: проверка скобок {#stek-proverka-skobok}

```python
def is_valid_parentheses(text: str) -> bool:
    opening_by_closing = {
        ")": "(",
        "]": "[",
        "}": "{",
    }
    stack: list[str] = []

    for character in text:
        if character not in opening_by_closing:
            # Открывающую скобку запоминаем до появления парной закрывающей.
            stack.append(character)
            continue

        if not stack:
            # Закрывающая скобка появилась, но открывающей перед ней нет.
            return False

        if stack.pop() != opening_by_closing[character]:
            # Последняя открытая скобка должна соответствовать текущей.
            return False

    # После корректной строки незакрытых скобок оставаться не должно.
    return not stack
```

Каждая скобка добавляется или удаляется один раз.

- Время: `O(n)`.
- Память: `O(n)` в худшем случае.

### Очередь: обход дерева по уровням {#ochered-obkhod-dereva-po-urovnyam}

```python
from collections import deque


def level_order(root: "TreeNode | None") -> list[list[int]]:
    if root is None:
        return []

    queue = deque([root])
    levels: list[list[int]] = []

    while queue:
        level: list[int] = []

        # len(queue) фиксирует количество узлов именно текущего уровня.
        for _ in range(len(queue)):
            node = queue.popleft()
            level.append(node.value)

            if node.left is not None:
                queue.append(node.left)

            if node.right is not None:
                queue.append(node.right)

        levels.append(level)

    return levels
```

`popleft()` извлекает самый старый узел. Поэтому дерево обрабатывается сверху вниз, уровень за уровнем.

### Связный список: разворот {#svyaznyy-spisok-razvorot}

```python
def reverse_list(head: "ListNode | None") -> "ListNode | None":
    previous = None
    current = head

    while current is not None:
        # Сначала сохраняем хвост, иначе потеряем оставшуюся часть списка.
        next_node = current.next

        # Меняем направление текущей ссылки.
        current.next = previous

        # Сдвигаем оба указателя на один узел вперед.
        previous = current
        current = next_node

    # После цикла previous указывает на новую голову.
    return previous
```

- Время: `O(n)`.
- Дополнительная память: `O(1)`.

## Задачи для самостоятельного решения {#zadachi-dlya-samostoyatelnogo-resheniya}

### Задача 1. Очередь через два стека {#zadacha-1-ochered-cherez-dva-steka}

Реализуй класс очереди с операциями `push`, `pop`, `peek` и `empty`, используя только два обычных списка как стеки.

Требование: объясни, почему `pop` имеет амортизированную сложность `O(1)`, хотя иногда переносит сразу несколько элементов.

### Задача 2. Следующий более теплый день {#zadacha-2-sleduyushchiy-bolee-teplyy-den}

Для каждой температуры верни количество дней до следующего более теплого дня. Если такого дня нет, запиши `0`.

```text
[73, 74, 75, 71, 69, 72, 76, 73] -> [1, 1, 4, 2, 1, 1, 0, 0]
```

Решение должно работать за `O(n)`. Определи, что нужно хранить в монотонном стеке: значения или индексы.
