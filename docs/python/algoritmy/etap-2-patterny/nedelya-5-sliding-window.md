## Цель недели {#tsel-nedeli}

Научиться обрабатывать непрерывные участки списка или строки за один проход.

После недели нужно уметь:

- отличать фиксированное окно от динамического;
- определять состояние окна;
- добавлять новый правый элемент;
- удалять старый левый элемент;
- формулировать условие допустимости;
- объяснять линейную сложность цикла с внутренним `while`.

## Что такое окно {#chto-takoe-okno}

Окно - непрерывный диапазон от `left` до `right` включительно.

```text
numbers = [2, 1, 5, 1, 3, 2]
              └─────┘
              left  right
```

Вместо пересчета всего диапазона при каждом сдвиге алгоритм обновляет только то, что изменилось:

- новый элемент справа добавляется;
- старый элемент слева удаляется.

## Когда искать Sliding Window {#kogda-iskat-sliding-window}

Сигналы в условии:

- подстрока или подмассив;
- непрерывный участок;
- максимальная или минимальная длина;
- сумма, частота или количество внутри диапазона;
- не более `k` разных элементов;
- не более `k` замен;
- все элементы окна должны удовлетворять ограничению.

Если элементы можно выбирать из произвольных позиций, Sliding Window обычно не подходит.

## Фиксированное окно {#fiksirovannoe-okno}

Размер окна известен заранее.

Пример: найти максимальную сумму трех соседних элементов.

### Медленное решение {#medlennoe-reshenie}

```python
def max_sum_slow(numbers: list[int], window_size: int) -> int:
    best_sum = float("-inf")

    for start in range(len(numbers) - window_size + 1):
        # Каждый раз заново суммируем все элементы окна.
        current_sum = sum(numbers[start : start + window_size])
        best_sum = max(best_sum, current_sum)

    return int(best_sum)
```

Для каждого из `n` положений выполняется сумма до `window_size` элементов. Время - `O(n * window_size)`.

### Оптимальное решение {#optimalnoe-reshenie}

```python
def max_sum(numbers: list[int], window_size: int) -> int:
    if window_size <= 0 or window_size > len(numbers):
        raise ValueError("window_size is out of range")

    # Первое окно нужно посчитать полностью только один раз.
    window_sum = sum(numbers[:window_size])
    best_sum = window_sum

    for right in range(window_size, len(numbers)):
        # Новый правый элемент теперь входит в окно.
        window_sum += numbers[right]

        # Элемент перед новой левой границей выходит из окна.
        removed_index = right - window_size
        window_sum -= numbers[removed_index]

        best_sum = max(best_sum, window_sum)

    return best_sum
```

### Пошаговый разбор {#poshagovyy-razbor}

```text
numbers = [2, 1, 5, 1, 3, 2]
window_size = 3
```

| Окно | Сумма | Лучший результат |
| --- | --- | --- |
| `[2, 1, 5]` | 8 | 8 |
| `[1, 5, 1]` | `8 + 1 - 2 = 7` | 8 |
| `[5, 1, 3]` | `7 + 3 - 1 = 9` | 9 |
| `[1, 3, 2]` | `9 + 2 - 5 = 6` | 9 |

- Время: `O(n)`.
- Память: `O(1)`.

## Динамическое окно {#dinamicheskoe-okno}

Размер окна заранее неизвестен. Правая граница расширяет диапазон, а левая сдвигается, когда ограничение нарушено.

Общий шаблон:

```python
left = 0

for right, value in enumerate(values):
    # Добавить value в состояние окна.

    while window_is_invalid:
        # Удалить values[left] из состояния.
        left += 1

    # В этом месте окно снова допустимо.
    # Можно обновить ответ.
```

## Пример 2. Самая длинная подстрока без повторов {#primer-2-samaya-dlinnaya-podstroka-bez-povtorov}

Состояние окна - последняя позиция каждого символа.

```python
def longest_unique_substring(text: str) -> int:
    last_index: dict[str, int] = {}
    left = 0
    best_length = 0

    for right, character in enumerate(text):
        if character in last_index:
            # Переносим left за предыдущее появление символа.
            # max не позволяет границе вернуться назад.
            left = max(left, last_index[character] + 1)

        # Текущее появление становится последним известным.
        last_index[character] = right

        # Обе границы входят в окно.
        current_length = right - left + 1
        best_length = max(best_length, current_length)

    return best_length
```

### Почему нужен max {#pochemu-nuzhen-max}

Рассмотрим `"abba"`.

После второго `b` левая граница переместится на индекс `2`. Когда встретится последний `a`, его старый индекс равен `0`. Простое присваивание вернуло бы `left` назад на `1`, хотя элементы до индекса `2` уже исключены.

```python
left = max(left, last_index[character] + 1)
```

Поэтому левая граница никогда не уменьшается.

- Время: `O(n)`.
- Память: `O(k)`, где `k` - количество разных символов.

## Пример 3. Минимальная длина подмассива {#primer-3-minimalnaya-dlina-podmassiva}

Даны положительные числа и `target`. Нужно найти минимальную длину непрерывного участка с суммой не меньше `target`.

```python
def min_subarray_length(numbers: list[int], target: int) -> int:
    left = 0
    window_sum = 0
    best_length = len(numbers) + 1  # Пока допустимое окно не найдено.

    for right, number in enumerate(numbers):
        window_sum += number  # Расширяем окно справа.

        while window_sum >= target:
            # Текущее окно уже подходит. Запоминаем его длину.
            current_length = right - left + 1
            best_length = min(best_length, current_length)

            # Пробуем сделать подходящее окно еще короче.
            window_sum -= numbers[left]
            left += 1

    if best_length == len(numbers) + 1:
        return 0

    return best_length
```

### Почему важны положительные числа {#pochemu-vazhny-polozhitelnye-chisla}

Если все числа положительные:

- добавление справа не уменьшает сумму;
- удаление слева не увеличивает сумму.

Это дает предсказуемое движение границ. С отрицательными числами обычная логика окна может перестать работать, потому что расширение способно уменьшить сумму.

## Почему вложенный while не дает O(n²) {#pochemu-vlozhennyy-while-ne-daet-o-n2}

Правая граница проходит список один раз. Левая граница тоже движется только вперед и проходит не более `n` позиций.

Общее количество сдвигов:

```text
n движений right + не более n движений left = O(n)
```

Вложенность в коде сама по себе не определяет сложность. Важно посчитать суммарное количество итераций.

## Что хранить в состоянии окна {#chto-khranit-v-sostoyanii-okna}

| Условие | Состояние |
| --- | --- |
| Сумма элементов | Число `window_sum` |
| Количество нулей | Счетчик |
| Разные символы | `dict` с частотами |
| Наличие повторов | `set` или последние индексы |
| Максимум окна | Монотонный `deque` на следующем этапе |

Не храни весь срез окна, если ответ можно поддерживать несколькими счетчиками.

## Two Pointers или Sliding Window {#two-pointers-ili-sliding-window}

Оба паттерна используют две границы, но цель отличается.

- Two Pointers обычно сравнивает или переставляет отдельные элементы.
- Sliding Window поддерживает состояние всего непрерывного диапазона.

Если в решении есть сумма, частоты или количество элементов между границами, это сильный признак окна.

## Частые ошибки {#chastye-oshibki}

1. Обновлять ответ, пока окно еще нарушает ограничение.
2. Забыть удалить левый элемент из суммы или частот.
3. Уменьшить частоту, но не удалить ключ с нулем, если количество ключей важно.
4. Передвинуть `left` только один раз вместо `while`.
5. Применить окно к подпоследовательности, которая не обязана быть непрерывной.
6. Использовать условие, которое не является монотонным.
7. Пересчитывать состояние всего окна после каждого сдвига.

## План занятий {#plan-zanyatiy}

1. Реализуй фиксированное окно для суммы и среднего.
2. Реализуй динамическое окно с числовым ограничением.
3. Добавь частотный словарь для строк.
4. Для каждого решения сформулируй условие допустимости окна.
5. Объясни, почему обе границы движутся только вперед.

## Задачи для самостоятельного решения {#zadachi-dlya-samostoyatelnogo-resheniya}

### Задача 1. Максимальная серия единиц после замен {#zadacha-1-maksimalnaya-seriya-edinits-posle-zamen}

Дан список из нулей и единиц. Разрешено заменить не более `k` нулей на единицы. Найди максимальную длину непрерывной серии единиц.

```text
numbers = [1, 1, 0, 0, 1, 1, 1, 0]
k = 2
result = 7
```

Состояние окна должно хранить количество нулей. Объясни, когда нужно сдвигать левую границу.

### Задача 2. Перестановка в строке {#zadacha-2-perestanovka-v-stroke}

Даны строки `pattern` и `text`. Определи, содержит ли `text` подстроку, являющуюся перестановкой `pattern`.

```text
pattern = "ab"
text = "eidbaooo"
result = True
```

Подумай, почему размер окна фиксирован и какие частоты нужно сравнивать.
