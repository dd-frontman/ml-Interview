## Цель недели {#tsel-nedeli}

Научиться использовать сортировку как подготовительный шаг, который превращает хаотичные диапазоны в последовательность для одного линейного прохода.

После недели нужно уметь:

- выбирать ключ сортировки;
- объяснять разницу между `sorted()` и `.sort()`;
- использовать стабильность сортировки;
- распознавать задачи на интервалы;
- объединять пересечения;
- вставлять новый интервал;
- проверять конфликты встреч;
- понимать базовую идею sweep line.

## Зачем сортировать перед алгоритмом {#zachem-sortirovat-pered-algoritmom}

Сортировка стоит `O(n log n)`, но после нее часто достаточно одного прохода `O(n)`.

Без сортировки для каждого интервала пришлось бы сравнивать все остальные, что может дать `O(n²)`.

Общая сложность:

```text
O(n log n) + O(n) = O(n log n)
```

## sorted и list.sort {#sorted-i-list-sort}

`sorted()` создает новый список:

```python
numbers = [3, 1, 2]
sorted_numbers = sorted(numbers)

# numbers остается [3, 1, 2].
# sorted_numbers содержит [1, 2, 3].
```

`.sort()` изменяет исходный список и возвращает `None`:

```python
numbers = [3, 1, 2]
result = numbers.sort()

# numbers теперь [1, 2, 3].
# result равен None.
```

На интервью заранее уточни, можно ли менять входные данные.

## Ключ сортировки {#klyuch-sortirovki}

`key` получает элемент и возвращает значение для сравнения.

```python
words = ["pear", "fig", "apple", "kiwi"]

# Сначала сравнивается длина, затем само слово.
ordered_words = sorted(words, key=lambda word: (len(word), word))

# Результат: ['fig', 'kiwi', 'pear', 'apple'].
```

Кортежи сравниваются слева направо:

1. Сначала `len(word)`.
2. При одинаковой длине - `word`.

Для числового критерия по убыванию удобно изменить знак:

```python
students = [
    {"name": "Alex", "score": 90},
    {"name": "Bob", "score": 100},
    {"name": "Diana", "score": 90},
]

ordered_students = sorted(
    students,
    key=lambda student: (-student["score"], student["name"]),
)

# Порядок: Bob, Alex, Diana.
```

## Стабильность сортировки {#stabilnost-sortirovki}

Сортировка Python стабильна: элементы с одинаковым ключом сохраняют исходный взаимный порядок.

Это позволяет сортировать по нескольким критериям в несколько проходов, начиная со второстепенного критерия. Но составной ключ обычно проще прочитать.

## Что такое интервал {#chto-takoe-interval}

Интервал обычно хранится как пара:

```text
[start, end]
```

Перед решением уточни:

- входят ли границы в интервал;
- считается ли касание пересечением;
- может ли `start` быть больше `end`;
- отсортированы ли интервалы;
- можно ли менять входной список.

Например, для встреч `[10, 11]` и `[11, 12]` пересечение зависит от смысла границ: первая встреча может закончиться ровно в момент начала второй.

## Пример 1. Объединение интервалов {#primer-1-obedinenie-intervalov}

Даны интервалы в произвольном порядке. Нужно объединить пересекающиеся.

### Идея {#ideya}

После сортировки по началу новый интервал может пересекаться только с последним уже объединенным интервалом.

```python
def merge_intervals(intervals: list[list[int]]) -> list[list[int]]:
    if not intervals:
        return []

    # Создаем новый список, чтобы не менять порядок исходного входа.
    ordered = sorted(intervals, key=lambda interval: interval[0])

    # Копия нужна, чтобы изменение end не изменило объект из ordered.
    merged = [ordered[0].copy()]

    for current_start, current_end in ordered[1:]:
        last = merged[-1]
        last_end = last[1]

        if current_start <= last_end:
            # Интервалы пересекаются. Расширяем правую границу.
            last[1] = max(last_end, current_end)
        else:
            # Между интервалами есть разрыв. Начинаем новую группу.
            merged.append([current_start, current_end])

    return merged
```

### Пошаговый разбор {#poshagovyy-razbor}

```text
intervals = [[1, 3], [8, 10], [2, 6], [9, 12]]
ordered = [[1, 3], [2, 6], [8, 10], [9, 12]]
```

| Текущий интервал | Последний объединенный | Действие | Результат |
| --- | --- | --- | --- |
| `[2, 6]` | `[1, 3]` | Пересекаются | Один интервал `[1, 6]` |
| `[8, 10]` | `[1, 6]` | Есть разрыв | Интервалы `[1, 6]` и `[8, 10]` |
| `[9, 12]` | `[8, 10]` | Пересекаются | Интервалы `[1, 6]` и `[8, 12]` |

- Сортировка: `O(n log n)`.
- Проход: `O(n)`.
- Итоговое время: `O(n log n)`.
- Память результата: `O(n)`.

## Пример 2. Вставка интервала {#primer-2-vstavka-intervala}

Дан уже отсортированный список непересекающихся интервалов и новый интервал.

Решение состоит из трех частей:

1. Добавить интервалы, которые полностью находятся слева.
2. Объединить все пересечения.
3. Добавить интервалы, которые находятся справа.

```python
def insert_interval(
    intervals: list[list[int]],
    new_interval: list[int],
) -> list[list[int]]:
    result: list[list[int]] = []
    index = 0
    new_start, new_end = new_interval

    # Часть 1: интервалы заканчиваются до начала нового.
    while index < len(intervals) and intervals[index][1] < new_start:
        result.append(intervals[index])
        index += 1

    # Часть 2: интервалы пересекаются с новым.
    while index < len(intervals) and intervals[index][0] <= new_end:
        new_start = min(new_start, intervals[index][0])
        new_end = max(new_end, intervals[index][1])
        index += 1

    result.append([new_start, new_end])

    # Часть 3: оставшиеся интервалы полностью находятся справа.
    result.extend(intervals[index:])

    return result
```

Список уже отсортирован, поэтому дополнительная сортировка не нужна.

- Время: `O(n)`.
- Память результата: `O(n)`.

## Пример 3. Можно ли посетить все встречи {#primer-3-mozhno-li-posetit-vse-vstrechi}

После сортировки по началу достаточно сравнивать соседние встречи.

```python
def can_attend_all(meetings: list[tuple[int, int]]) -> bool:
    ordered = sorted(meetings, key=lambda meeting: meeting[0])

    for index in range(1, len(ordered)):
        previous_end = ordered[index - 1][1]
        current_start = ordered[index][0]

        if current_start < previous_end:
            # Текущая встреча началась до завершения предыдущей.
            return False

    return True
```

Здесь касание не считается пересечением: встреча может начаться в момент окончания предыдущей.

## Выбор критерия сортировки {#vybor-kriteriya-sortirovki}

Критерий зависит от цели:

| Задача | Частый критерий |
| --- | --- |
| Объединить интервалы | По началу |
| Проверить пересечения | По началу |
| Выбрать максимум непересекающихся | По концу |
| Посчитать одновременные события | Отдельные события начала и конца |

Сортировка по концу в задаче выбора интервалов позволяет раньше освободить пространство для следующих интервалов.

## Sweep Line простыми словами {#sweep-line-prostymi-slovami}

Sweep Line превращает каждый интервал в события:

- начало увеличивает количество активных интервалов;
- конец уменьшает количество активных интервалов.

```python
def max_overlapping(intervals: list[tuple[int, int]]) -> int:
    events: list[tuple[int, int]] = []

    for start, end in intervals:
        events.append((start, 1))  # Интервал начал действовать.
        events.append((end, -1))  # Интервал закончил действовать.

    # При одинаковом времени -1 идет перед 1.
    # Значит, завершение освобождает ресурс перед новым началом.
    events.sort(key=lambda event: (event[0], event[1]))

    active = 0
    best = 0

    for _, change in events:
        active += change
        best = max(best, active)

    return best
```

Правило порядка событий при одинаковом времени зависит от того, считается ли касание пересечением.

## Частые ошибки {#chastye-oshibki}

1. Начать объединение без сортировки.
2. Сравнивать новый интервал с исходным предыдущим, а не с последним объединенным.
3. Забыть добавить последний накопленный интервал.
4. Изменить исходные вложенные списки через общие ссылки.
5. Потерять исходные индексы после сортировки.
6. Выбрать сортировку по началу там, где жадный выбор требует сортировки по концу.
7. Не определить порядок начала и конца в одной временной точке.

## Задачи для самостоятельного решения {#zadachi-dlya-samostoyatelnogo-resheniya}

### Задача 1. Удаление пересечений {#zadacha-1-udalenie-peresecheniy}

Дан список интервалов. Найди минимальное количество интервалов, которые нужно удалить, чтобы оставшиеся не пересекались.

```text
[[1, 2], [2, 3], [3, 4], [1, 3]] -> 1
```

Подумай, почему для жадного выбора полезно сортировать интервалы по правой границе.

### Задача 2. Минимальное количество переговорных {#zadacha-2-minimalnoe-kolichestvo-peregovornykh}

Даны интервалы встреч. Найди минимальное количество комнат, необходимое для проведения всех встреч.

```text
[[0, 30], [5, 10], [15, 20]] -> 2
```

Реши задачу двумя способами:

1. Sweep Line через события начала и конца.
2. Min-heap с временами окончания активных встреч.

Сравни временную и пространственную сложность.
