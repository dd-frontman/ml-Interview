## Что изучаем {#chto-izuchaem}

Итератор отдает значения по одному и помнит, где остановился. Генератор - самый короткий способ написать итератор: обычная функция, в которой вместо `return` стоит `yield`.

```python
def countdown(n: int):
    while n > 0:
        yield n
        n -= 1


for value in countdown(3):
    print(value)

# 3
# 2
# 1
```

Где это нужно на практике:

- прочитать файл на 10 ГБ построчно, не загружая его в память целиком;
- отдавать данные в модель батчами;
- собрать конвейер обработки: прочитать, очистить, отфильтровать, сгруппировать;
- работать с бесконечными потоками: события, логи, таймеры;
- по очереди выполнять несколько задач в одном потоке.

## Главная идея: склад и конвейер {#glavnaya-ideya-sklad-i-konveyer}

Список похож на склад. Все товары уже лежат на полках: можно посчитать их, взять любой по номеру, пройтись по складу несколько раз. Но склад занимает место.

Итератор похож на конвейерную ленту. Товары приезжают по одному, когда ты их забираешь. Посчитать заранее, сколько их будет, нельзя, вернуться назад тоже. Зато места почти не нужно, и лента может быть бесконечной.

```python
squares_list = [x * x for x in range(1_000_000)]  # склад: миллион чисел в памяти
squares_gen = (x * x for x in range(1_000_000))   # конвейер: числа считаются по запросу
```

| | Список | Итератор или генератор |
| --- | --- | --- |
| Когда считаются значения | сразу, все | по одному, при запросе |
| Память | растет с количеством элементов | почти не зависит от количества |
| `len()` и индекс `[i]` | есть | нет |
| Повторный обход | сколько угодно | один раз |
| Бесконечная последовательность | невозможна | возможна |

## Основные термины {#osnovnye-terminy}

| Термин | Значение |
| --- | --- |
| Итерируемый объект (iterable) | объект, который можно перебрать в `for`: список, строка, словарь, файл |
| Итератор (iterator) | объект, который выдает следующий элемент и помнит позицию |
| `iter(obj)` | получить итератор из итерируемого объекта |
| `next(it)` | взять из итератора следующий элемент |
| `StopIteration` | исключение, которым итератор сообщает, что элементы закончились |
| Генераторная функция | функция с `yield`, при вызове возвращает генератор |
| Генератор | итератор, который создает генераторная функция или генераторное выражение |
| Генераторное выражение | запись вида `(x for x in items)` |
| Ленивые вычисления | значение считается только тогда, когда его попросили |
| Исчерпание | состояние итератора, у которого закончились элементы |

## Аналогия с JS {#analogiya-s-js}

Если знаешь итераторы в JS, почти все уже знакомо:

| Python | JS |
| --- | --- |
| `__iter__` | `[Symbol.iterator]()` |
| `__next__` и `StopIteration` | `next()` возвращает `{ value, done }` |
| `for x in obj` | `for (const x of obj)` |
| `def f(): yield x` | `function* f() { yield x }` |
| `yield from other` | `yield* other` |
| `(x * 2 for x in xs)` | `xs.values().map(x => x * 2)`, вспомогательные методы итераторов из ES2025 |
| `gen.send(value)` | `gen.next(value)` |
| `gen.throw(error)` | `gen.throw(error)` |
| `gen.close()` | `gen.return()` |
| `itertools` | встроенного аналога нет, ближе всего методы итераторов из ES2025 и `lodash` |

Главное отличие: в Python конец перебора обозначается исключением `StopIteration`, а в JS объектом `{ done: true }`.

## Когда что использовать {#kogda-chto-ispolzovat}

| Задача | Инструмент |
| --- | --- |
| Данных немного, нужен повторный обход или индекс | список |
| Большой файл, поток событий, батчи | генератор |
| Простая ленивая трансформация в одну строку | генераторное выражение |
| Объект со сложным состоянием и несколькими методами | класс с `__iter__` |
| Склеить, нарезать, сгруппировать поток | `itertools` |
| Генератор состоит из нескольких других | `yield from` |
