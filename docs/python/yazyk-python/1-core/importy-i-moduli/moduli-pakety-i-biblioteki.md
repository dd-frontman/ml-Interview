## Модуль {#modul}

**Модуль** — это файл с расширением `.py`.

```text
math_operations.py
```

Внутри модуля можно объявлять функции, классы и переменные:

```python
# math_operations.py

PI = 3.14159


def add(x, y):
    return x + y


def subtract(x, y):
    return x - y
```

Другой файл может импортировать эти имена и использовать готовую логику.

## Пакет {#paket}

**Пакет** — это директория, которая объединяет связанные модули:

```text
calculator/
├── __init__.py
├── math_operations.py
└── validators.py
main.py
```

В этой структуре:

- `calculator` — пакет;
- `math_operations` и `validators` — модули внутри пакета;
- `main.py` — отдельный модуль, который использует пакет.

Файл `__init__.py` обозначает обычный пакет и может содержать код его инициализации. В современном Python существуют также namespace packages без `__init__.py`, но для учебных и небольших проектов явный файл обычно делает структуру понятнее.

## Библиотека {#biblioteka}

Слово **библиотека** обычно обозначает набор готового кода для решения определённой группы задач. Библиотека может состоять из одного или нескольких пакетов и модулей.

Например:

- `random` — модуль стандартной библиотеки;
- `requests` — сторонняя библиотека и импортируемый пакет;
- `pandas` — сторонняя библиотека с большим количеством внутренних модулей.

В обычной речи слова «библиотека» и «пакет» иногда используют как близкие, но технически пакет — это способ организации импортируемых модулей.

## Стандартная библиотека {#standartnaya-biblioteka}

Стандартная библиотека устанавливается вместе с Python. Её не нужно загружать через `pip`.

Примеры:

- `random` — случайный выбор и генерация чисел;
- `json` — работа с JSON;
- `datetime` — дата и время;
- `pathlib` — работа с путями;
- `csv` — чтение и запись CSV.

```python
import datetime
import json
import random
```

## Сторонние пакеты {#storonnie-pakety}

Сторонние библиотеки устанавливаются отдельно:

```bash
python -m pip install requests
```

После установки пакет можно импортировать:

```python
import requests
```

Если пакет не установлен в активном окружении, Python вызовет `ModuleNotFoundError`.

Команда `python -m pip` явно использует `pip`, принадлежащий выбранному интерпретатору Python. Это уменьшает риск установить пакет не в то окружение.

## Собственные модули {#sobstvennye-moduli}

Функции из собственного файла импортируются так же, как функции библиотек:

```python
from calculator.math_operations import add, subtract

print(add(10, 5))       # 15
print(subtract(10, 5))  # 5
```

Путь читается слева направо:

1. Открыть пакет `calculator`.
2. Найти модуль `math_operations`.
3. Связать имена `add` и `subtract` с текущим модулем.

## Самостоятельная практика {#samostoyatelnaya-praktika}

1. Создай модуль `temperature.py` с функцией перевода градусов Цельсия в Фаренгейты.
2. Создай пакет `geometry` с модулями `circle.py` и `rectangle.py`.
3. Объясни своими словами разницу между модулем, пакетом и библиотекой.
