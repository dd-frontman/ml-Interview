## Ошибки ограниченных ресурсов {#oshibki-ogranichennykh-resursov}

Программа использует стек вызовов, оперативную память, файлы и сетевые соединения. Эти ресурсы ограничены, поэтому корректная инструкция тоже может завершиться исключением.

## `RecursionError` {#recursionerror}

Функция вызвала себя слишком много раз.

```python
def repeat():
    return repeat()


repeat()
# RecursionError: maximum recursion depth exceeded
```

В примере нет условия остановки.

Корректная рекурсия должна приближаться к базовому случаю:

```python
def countdown(number):
    if number == 0:
        return "Готово"

    return countdown(number - 1)


print(countdown(3))  # Готово
```

Не повышайте лимит рекурсии автоматически. Сначала проверьте алгоритм и возможность заменить рекурсию циклом.

## `MemoryError` {#memoryerror}

Операции не хватило доступной оперативной памяти.

Частые причины:

- создаётся слишком большая коллекция;
- данные многократно копируются;
- цикл бесконечно накапливает элементы;
- большой файл загружается целиком;
- несколько тяжёлых процессов работают одновременно.

Что проверить:

1. размер входных данных;
2. генераторы вместо готовых списков;
3. обработку файла частями;
4. освобождение ненужных ссылок;
5. профилирование памяти.

`try/except MemoryError` редко решает основную проблему: алгоритм уже потребляет слишком много памяти.

## `RuntimeError` {#runtimeerror}

Общая ошибка выполнения, для которой не подошёл более конкретный класс.

Библиотеки могут создавать `RuntimeError`, когда операция допустима синтаксически, но текущее состояние системы не позволяет её выполнить.

При собственных проверках сначала подумайте, нет ли более точного класса: `ValueError`, `TypeError` или собственного исключения предметной области.

## `NotImplementedError` {#notimplementederror}

Метод должен быть реализован в дочернем классе, но реализация отсутствует.

```python
class Storage:
    def save(self, data):
        raise NotImplementedError("Метод save должен быть переопределён")
```

```python
class FileStorage(Storage):
    def save(self, data):
        return f"Сохранено: {data}"


storage = FileStorage()
print(storage.save("отчёт"))  # Сохранено: отчёт
```

Не путайте:

- `NotImplementedError` — исключение;
- `NotImplemented` — специальное значение для протоколов операций.

Для строгих абстрактных интерфейсов часто лучше использовать модуль `abc`.

## `AssertionError` {#assertionerror}

Условие `assert` оказалось ложным.

```python
age = -1
assert age >= 0, "Возраст не может быть отрицательным"


# AssertionError: Возраст не может быть отрицательным
```

`assert` подходит для внутренних инвариантов и тестов. Проверку пользовательских данных лучше выполнять явно:

```python
if age < 0:
    raise ValueError("Возраст не может быть отрицательным")
```

Проверки `assert` могут быть отключены при оптимизированном запуске Python, поэтому они не должны отвечать за критическую валидацию.

## `ConnectionError` {#connectionerror}

Проблема возникла при установке или использовании сетевого соединения.

Подклассы включают:

- `ConnectionRefusedError` — удалённая сторона отказала в соединении;
- `ConnectionResetError` — соединение принудительно сброшено;
- `BrokenPipeError` — запись выполняется в уже закрытое соединение.

Сетевую проблему иногда можно повторить через паузу, но повтор должен иметь ограничение по количеству попыток.

## `TimeoutError` {#timeouterror}

Операция не завершилась за установленное время.

Причиной может быть медленный сервер, сеть, блокировка ресурса или слишком маленький тайм-аут.

Сторонние библиотеки часто имеют собственные классы тайм-аутов. Например, `requests` использует `requests.exceptions.Timeout`, поэтому проверяйте документацию конкретной библиотеки.

## Ожидаемая проблема или баг {#ozhidaemaya-problema-ili-bag}

| Исключение | Чаще всего |
| --- | --- |
| `RecursionError` | ошибка алгоритма |
| `MemoryError` | неэффективный алгоритм или слишком большие данные |
| `NotImplementedError` | незавершённая реализация |
| `AssertionError` | нарушен внутренний инвариант |
| `ConnectionError` | ожидаемая внешняя проблема |
| `TimeoutError` | ожидаемая внешняя проблема или неправильная настройка |

## Самостоятельная практика {#samostoyatelnaya-praktika}

1. Добавьте базовый случай в рекурсивную функцию без остановки.
2. Перепишите создание большого списка на генератор.
3. Объясните, почему пользовательский возраст нельзя проверять только через `assert`.
4. Составьте алгоритм повторения сетевого запроса максимум три раза.

## Краткое повторение {#kratkoe-povtorenie}

- `RecursionError` часто указывает на неправильную остановку рекурсии.
- `MemoryError` требует изменения обработки данных, а не только `except`.
- `NotImplementedError` обозначает отсутствующую реализацию.
- `assert` предназначен для внутренних проверок.
- Сетевые исключения могут быть ожидаемыми, но повторы должны быть ограничены.
