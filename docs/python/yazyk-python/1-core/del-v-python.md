## Зачем нужен `del` {#zachem-nuzhen-del}

Инструкция `del` удаляет указанную цель. Такой целью может быть:

- имя переменной;
- элемент или срез списка;
- ключ словаря;
- атрибут объекта.

Например, из списка нужно убрать товар с индексом `1`:

```python
products = ["ноутбук", "мышь", "клавиатура"]

del products[1]

print(products)  # ['ноутбук', 'клавиатура']
```

`del` - это **инструкция удаления**, а не оператор, возвращающий значение. Поэтому результат `del` нельзя присвоить переменной.

```python
# result = del products[1]  # SyntaxError
```

## Удаление имени переменной {#udalenie-imeni-peremennoy}

Переменная в Python - это имя, связанное с объектом. Инструкция `del` разрывает эту связь и удаляет имя из текущей области видимости.

```python
language = "Python"

print(language)  # Python

del language

# print(language)  # NameError: name 'language' is not defined
```

После `del language` имени `language` больше нет. Повторное обращение к нему вызывает `NameError`.

### Удаляется ли сам объект {#udalyaetsya-li-sam-obekt}

`del` не означает «немедленно уничтожить объект». Он удаляет только указанную ссылку на объект. Если на тот же объект указывает другое имя, объект продолжит существовать.

```python
numbers = [10, 20, 30]
same_numbers = numbers

del numbers

print(same_numbers)  # [10, 20, 30]
```

Имена `numbers` и `same_numbers` ссылались на один список. Удалилось только имя `numbers`, поэтому список по-прежнему доступен через `same_numbers`.

Когда ссылок на объект больше не остаётся, Python может освободить занимаемую им память. Точный момент освобождения зависит от реализации Python и работы сборщика мусора, поэтому `del` не следует использовать как команду принудительного очищения памяти.

Несколько имён можно удалить одной инструкцией:

```python
first = 10
second = 20

del first, second
```

Обычно отдельные инструкции читаются понятнее, поэтому такую сокращённую запись используют редко.

## Удаление элемента списка {#udalenie-elementa-spiska}

У списка можно удалить элемент по индексу:

```python
colors = ["красный", "зелёный", "синий"]

del colors[1]

print(colors)  # ['красный', 'синий']
```

После удаления список становится короче, а элементы справа сдвигаются влево. В примере `"синий"` переместился с индекса `2` на индекс `1`.

Отрицательный индекс также разрешён:

```python
numbers = [10, 20, 30]

del numbers[-1]

print(numbers)  # [10, 20]
```

Если такого индекса нет, Python вызовет `IndexError`:

```python
numbers = [10, 20]

# del numbers[5]  # IndexError: list assignment index out of range
```

## Удаление среза списка {#udalenie-sreza-spiska}

С помощью среза можно удалить сразу несколько элементов:

```python
numbers = [0, 1, 2, 3, 4, 5]

del numbers[1:4]

print(numbers)  # [0, 4, 5]
```

Срез `[1:4]` включает индексы `1`, `2` и `3`, но не включает индекс `4`.

Можно использовать шаг и удалить каждый второй элемент:

```python
numbers = [0, 1, 2, 3, 4, 5]

del numbers[::2]

print(numbers)  # [1, 3, 5]
```

Чтобы очистить весь список через `del`, удаляют полный срез:

```python
numbers = [10, 20, 30]

del numbers[:]

print(numbers)  # []
```

При этом имя `numbers` сохраняется и продолжает указывать на тот же, теперь пустой, список. Запись `del numbers` дала бы другой результат: она удалила бы само имя.

## Удаление ключа словаря {#udalenie-klyucha-slovarya}

В словаре `del` удаляет пару «ключ - значение» по ключу:

```python
user = {
    "name": "Alice",
    "age": 30,
    "city": "London",
}

del user["age"]

print(user)  # {'name': 'Alice', 'city': 'London'}
```

Если ключ отсутствует, возникнет `KeyError`:

```python
user = {"name": "Alice"}

# del user["age"]  # KeyError: 'age'
```

Если отсутствие ключа допустимо, безопаснее использовать `pop()` со значением по умолчанию:

```python
user = {"name": "Alice"}

removed_age = user.pop("age", None)

print(removed_age)  # None
print(user)         # {'name': 'Alice'}
```

## Удаление атрибута объекта {#udalenie-atributa-obekta}

Инструкция `del` может удалить атрибут экземпляра:

```python
class User:
    pass


user = User()
user.name = "Alice"

del user.name

print(hasattr(user, "name"))  # False
```

Повторное обращение к удалённому атрибуту обычно вызывает `AttributeError`.

```python
# print(user.name)  # AttributeError: 'User' object has no attribute 'name'
```

У классов с `@property` или собственным методом `__delattr__()` удаление атрибута может выполнять дополнительную логику или быть запрещено.

## `del`, `pop()`, `remove()` и `clear()` {#del-pop-remove-i-clear}

Эти инструменты похожи, но решают разные задачи:

| Запись | Что делает | Возвращает удалённое значение |
| --- | --- | --- |
| `del items[index]` | удаляет элемент по индексу | нет |
| `items.pop(index)` | удаляет элемент по индексу | да |
| `items.remove(value)` | удаляет первое совпавшее значение | нет |
| `items.clear()` | удаляет все элементы | нет |
| `del mapping[key]` | удаляет ключ словаря | нет |
| `mapping.pop(key)` | удаляет ключ словаря | да |

Если удалённое значение понадобится дальше, используй `pop()`:

```python
tasks = ["учиться", "отдыхать", "читать"]

completed_task = tasks.pop(0)

print(completed_task)  # учиться
print(tasks)           # ['отдыхать', 'читать']
```

Если значение получать не нужно и цель удаления уже известна, подходит `del`:

```python
tasks = ["учиться", "отдыхать", "читать"]

del tasks[0]

print(tasks)  # ['отдыхать', 'читать']
```

У множества нет индексов и ключей, поэтому запись `del values[0]` для `set` невозможна. Элементы множества удаляют методами `remove()` или `discard()`.

## `del` и `__del__` - не одно и то же {#del-i-del-ne-odno-i-to-zhe}

`del` - инструкция языка, которая удаляет имя, элемент или атрибут.

`__del__()` - специальный метод объекта, который Python может вызвать перед окончательным уничтожением объекта. Напрямую связывать эти механизмы не следует: выполнение `del variable` не гарантирует немедленный вызов `variable.__del__()`, потому что у объекта могут оставаться другие ссылки.

Для закрытия файлов, сетевых соединений и других ресурсов обычно используют менеджер контекста `with`, а не `__del__()`.

## Типичные ошибки {#tipichnye-oshibki}

### Путать удаление имени с очисткой списка {#putat-udalenie-imeni-s-ochistkoy-spiska}

```python
numbers = [1, 2, 3]

del numbers

# print(numbers)  # NameError: name 'numbers' is not defined
```

Если список должен остаться доступным, используй `numbers.clear()` или `del numbers[:]`.

### Удалять элементы списка во время обхода {#udalyat-elementy-spiska-vo-vremya-obkhoda}

При удалении элементы сдвигаются, поэтому цикл может пропустить некоторые значения:

```python
numbers = [2, 4, 6, 7]

for index, number in enumerate(numbers):
    if number % 2 == 0:
        del numbers[index]

print(numbers)  # [4, 7], число 4 было пропущено
```

Для фильтрации обычно понятнее создать новый список:

```python
numbers = [2, 4, 6, 7]
odd_numbers = [number for number in numbers if number % 2 != 0]

print(odd_numbers)  # [7]
```

### Удалять отсутствующий ключ без проверки {#udalyat-otsutstvuyushchiy-klyuch-bez-proverki}

Если ключ может отсутствовать, используй `dictionary.pop(key, default)` или сначала проверь `key in dictionary`.

## Задачи для практики {#zadachi-dlya-praktiki}

1. Дан список `letters = ["a", "b", "c", "d", "e"]`. Удали элементы с индексами от `1` до `3` включительно одной инструкцией `del`.
2. Дан словарь пользователя. Удали ключ `"password"`, а затем выведи оставшийся словарь.
3. Создай два имени, указывающих на один список. Удали первое имя и проверь, что список всё ещё доступен через второе.

## Краткое повторение {#kratkoe-povtorenie}

- `del name` удаляет имя из текущей области видимости;
- `del list[index]` удаляет элемент списка по индексу;
- `del list[start:stop]` удаляет срез;
- `del dictionary[key]` удаляет ключ и связанное с ним значение;
- `del object.attribute` удаляет атрибут объекта;
- `del` ничего не возвращает;
- удаление имени не гарантирует немедленного уничтожения объекта;
- если удалённое значение нужно получить, чаще подходит `pop()`.
