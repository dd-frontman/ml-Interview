## Что такое оператор {#chto-takoe-operator}

Оператор выполняет действие над одним или несколькими значениями. Значения, с которыми он работает, называются **операндами**.

```python
result = 10 + 5
```

Здесь `+` - оператор, а `10` и `5` - его операнды.

Один и тот же оператор может работать по-разному с разными типами:

```python
print(2 + 3)              # 5
print("Py" + "thon")      # Python
print([1, 2] + [3, 4])    # [1, 2, 3, 4]
```

## Арифметические операторы {#arifmeticheskie-operatory}

| Оператор | Действие | Пример | Результат |
| --- | --- | --- | --- |
| `+` | сложение | `5 + 2` | `7` |
| `-` | вычитание | `5 - 2` | `3` |
| `*` | умножение | `5 * 2` | `10` |
| `/` | обычное деление | `5 / 2` | `2.5` |
| `//` | деление с округлением вниз | `5 // 2` | `2` |
| `%` | остаток от деления | `5 % 2` | `1` |
| `**` | возведение в степень | `5 ** 2` | `25` |
| `@` | матричное умножение | `matrix_a @ matrix_b` | зависит от типа |

Оператор `@` предназначен для объектов, которые поддерживают матричное умножение, например массивов NumPy. Обычные числа и списки его не поддерживают.

## Унарные операторы {#unarnye-operatory}

Унарный оператор применяется к одному операнду.

| Оператор | Действие | Пример | Результат |
| --- | --- | --- | --- |
| `+x` | оставить числовой знак | `+5` | `5` |
| `-x` | изменить числовой знак | `-5` | `-5` |
| `~x` | инвертировать биты | `~5` | `-6` |
| `not x` | логическое отрицание | `not True` | `False` |

## Операторы сравнения {#operatory-sravneniya}

| Оператор | Проверка | Пример | Результат |
| --- | --- | --- | --- |
| `==` | значения равны | `5 == 5` | `True` |
| `!=` | значения не равны | `5 != 3` | `True` |
| `<` | меньше | `3 < 5` | `True` |
| `<=` | меньше или равно | `5 <= 5` | `True` |
| `>` | больше | `5 > 3` | `True` |
| `>=` | больше или равно | `5 >= 5` | `True` |

Сравнения можно объединять в цепочку:

```python
age = 25

print(18 <= age < 65)  # True
```

## Логические операторы {#logicheskie-operatory}

| Оператор | Действие | Пример | Результат |
| --- | --- | --- | --- |
| `and` | истина, если подходят оба условия | `True and False` | `False` |
| `or` | истина, если подходит хотя бы одно условие | `True or False` | `True` |
| `not` | изменить истинность на противоположную | `not True` | `False` |

`and` и `or` не всегда возвращают `bool`: они возвращают один из своих операндов и используют короткое замыкание.

```python
print(0 or "default")       # default
print("Alice" and "admin")  # admin
```

## Операторы принадлежности {#operatory-prinadlezhnosti}

| Оператор | Проверка | Пример | Результат |
| --- | --- | --- | --- |
| `in` | значение входит в коллекцию | `2 in [1, 2, 3]` | `True` |
| `not in` | значение не входит в коллекцию | `4 not in [1, 2, 3]` | `True` |

`not in` - единый составной оператор. Он читается как «не входит».

## Операторы идентичности {#operatory-identichnosti}

| Оператор | Проверка | Пример |
| --- | --- | --- |
| `is` | два имени указывают на один объект | `value is None` |
| `is not` | имена указывают на разные объекты | `value is not None` |

`is` не заменяет `==`. Оператор `==` сравнивает значения, а `is` - идентичность объектов. Для проверки `None` принято использовать `is None` и `is not None`.

## Побитовые операторы {#pobitovye-operatory}

Побитовые операторы работают с двоичным представлением целых чисел.

| Оператор | Действие | Пример | Результат |
| --- | --- | --- | --- |
| `&` | побитовое И | `5 & 3` | `1` |
| `\|` | побитовое ИЛИ | `5 \| 3` | `7` |
| `^` | исключающее ИЛИ, XOR | `5 ^ 3` | `6` |
| `~` | побитовое НЕ | `~5` | `-6` |
| `<<` | сдвиг битов влево | `5 << 1` | `10` |
| `>>` | сдвиг битов вправо | `5 >> 1` | `2` |

Например, `5` в двоичном виде - `101`, а `3` - `011`:

```text
101
011
---
001  # результат 5 & 3
```

## Присваивание {#prisvaivanie}

Обычное `=` и сокращенные присваивания являются синтаксисом инструкций присваивания. Они изменяют привязку имени или значение объекта, но сами не используются как обычные выражения.

| Запись | Эквивалентная идея | Действие |
| --- | --- | --- |
| `x = 5` | присвоить `5` имени `x` | обычное присваивание |
| `x += y` | `x = x + y` | сложить и присвоить |
| `x -= y` | `x = x - y` | вычесть и присвоить |
| `x *= y` | `x = x * y` | умножить и присвоить |
| `x /= y` | `x = x / y` | разделить и присвоить |
| `x //= y` | `x = x // y` | выполнить `//` и присвоить |
| `x %= y` | `x = x % y` | получить остаток и присвоить |
| `x **= y` | `x = x ** y` | возвести в степень и присвоить |
| `x @= y` | `x = x @ y` | выполнить матричное умножение |
| `x &= y` | `x = x & y` | выполнить побитовое И |
| `x \|= y` | `x = x \| y` | выполнить побитовое ИЛИ |
| `x ^= y` | `x = x ^ y` | выполнить XOR |
| `x <<= y` | `x = x << y` | сдвинуть влево и присвоить |
| `x >>= y` | `x = x >> y` | сдвинуть вправо и присвоить |

Сокращенное присваивание не всегда полностью совпадает с развернутой записью. Например, `+=` может изменить список на месте:

```python
items = [1, 2]
same_items = items
items += [3]

print(items)       # [1, 2, 3]
print(same_items)  # [1, 2, 3]
```

## Выражение присваивания `:=` {#vyrazhenie-prisvaivaniya}

Оператор `:=` появился в Python 3.8. Его называют **моржовым оператором** (walrus operator), потому что символы `:=` напоминают глаза и клыки моржа.

Главная идея: `:=` выполняет сразу два действия:

1. вычисляет выражение справа;
2. сохраняет результат в имени слева;
3. возвращает это же значение в текущее выражение.

```python
text = "Python"

if (length := len(text)) > 5:
    print(length)  # 6
```

### Как пример выполняется по шагам {#kak-primer-vypolnyaetsya-po-shagam}

В выражении `(length := len(text)) > 5` происходит следующее:

1. `len(text)` возвращает `6`;
2. значение `6` записывается в `length`;
3. выражение `(length := len(text))` тоже возвращает `6`;
4. Python проверяет `6 > 5`;
5. условие истинно, поэтому выполняется тело `if`.

Имя остается доступным после условия:

```python
text = "Python"

if (length := len(text)) > 5:
    print("Длинная строка")  # Длинная строка

print(length)  # 6
```

### Чем `:=` отличается от `=` {#chem-otlichaetsya-ot}

| `=` | `:=` |
| --- | --- |
| обычная инструкция присваивания | присваивание внутри выражения |
| связывает имя со значением | связывает имя и возвращает это значение |
| обычно занимает отдельную строку | используется внутри `if`, `while` и других выражений |
| `length = len(text)` | `(length := len(text))` |

Обычное присваивание нельзя поставить вместо условия:

```python
# SyntaxError: вместо проверки записано обычное присваивание
if length = len("Python"):
    print(length)
```

Без `:=` пример нужно разделить на две операции:

```python
text = "Python"
length = len(text)

if length > 5:
    print(length)  # 6
```

Оба варианта правильные. Обычное присваивание часто проще читать, поэтому `:=` не нужно использовать только ради сокращения одной строки.

### Когда `:=` полезен {#kogda-polezen}

`:=` полезен, когда вычисленное значение нужно и для проверки, и внутри блока.

```python
numbers = [10, 20, 30, 40]

if (count := len(numbers)) >= 4:
    print(f"Получено элементов: {count}")  # Получено элементов: 4
```

Без моржового оператора пришлось бы либо заранее создать `count`, либо дважды вызвать `len(numbers)`.

Еще одно применение - получать новое значение на каждой итерации `while` и сразу проверять, нужно ли продолжать цикл:

```python
words = iter(["Python", "ML", ""])

while (word := next(words, "")) != "":
    print(word)

# Python
# ML
```

На каждой итерации `next()` возвращает очередную строку и записывает ее в `word`. Пустая строка завершает цикл.

### Почему часто нужны скобки {#pochemu-chasto-nuzhny-skobki}

У `:=` очень низкий приоритет. Скобки явно показывают, какое значение нужно сохранить.

```python
text = "Python"

if (length := len(text)) > 5:
    print(length)  # 6
```

Без скобок смысл изменится:

```python
text = "Python"

if length := len(text) > 5:
    print(length)  # True
```

Во втором примере сначала вычисляется сравнение `len(text) > 5`, а уже его результат `True` записывается в `length`. Поэтому скобки здесь нужны не только для красоты.

### Ограничения `:=` {#ogranicheniya}

Слева должно находиться простое имя переменной:

```python
(value := 10)  # допустимо
```

Нельзя присваивать через `:=` атрибуту, элементу коллекции или нескольким именам:

```python
# SyntaxError
(user.name := "Alice")

# SyntaxError
(items[0] := 10)

# SyntaxError
((first, second) := (1, 2))
```

Отдельная запись без скобок тоже недопустима:

```python
# SyntaxError
value := 10
```

Для обычного отдельного присваивания нужен `=`:

```python
value = 10
```

### Когда `:=` лучше не использовать {#kogda-luchshe-ne-ispolzovat}

Не используй `:=`, если:

- значение не применяется повторно;
- обычное присваивание на отдельной строке понятнее;
- условие становится длинным и его приходится перечитывать;
- в одном выражении появляется несколько присваиваний.

Практическое правило: используй `:=`, когда оно убирает повторное вычисление и при этом делает код понятнее. Краткость сама по себе недостаточна.

## Условное выражение {#uslovnoe-vyrazhenie}

Условное выражение выбирает одно из двух значений:

```python
status = "adult" if age >= 18 else "minor"
```

Его часто называют тернарным оператором, потому что в записи участвуют три части:

1. значение при истинном условии;
2. условие;
3. значение при ложном условии.

## Операции с наивысшим приоритетом {#operatsii-s-naivysshim-prioritetom}

Следующие конструкции часто воспринимаются как операторы, хотя в справочнике Python они выделены как первичные операции:

| Синтаксис | Действие | Пример |
| --- | --- | --- |
| `obj.attribute` | получить атрибут | `user.name` |
| `obj[index]` | получить элемент по индексу или ключу | `items[0]` |
| `obj[start:stop]` | получить срез | `items[1:4]` |
| `func(arguments)` | вызвать объект | `len(items)` |

Они выполняются раньше арифметических, сравнительных и логических операторов.

## Приоритет операторов {#prioritet-operatorov}

Чем выше строка в таблице, тем раньше выполняется операция.

| Приоритет | Операторы и выражения | Назначение |
| --- | --- | --- |
| 1 | `obj.attr`, `obj[index]`, `obj(...)` | атрибут, индекс, срез, вызов |
| 2 | `await x` | ожидание в асинхронном коде |
| 3 | `**` | степень |
| 4 | `+x`, `-x`, `~x` | унарные операции |
| 5 | `*`, `@`, `/`, `//`, `%` | умножение и деление |
| 6 | `+`, `-` | сложение и вычитание |
| 7 | `<<`, `>>` | битовые сдвиги |
| 8 | `&` | побитовое И |
| 9 | `^` | XOR |
| 10 | `\|` | побитовое ИЛИ |
| 11 | `<`, `<=`, `>`, `>=`, `!=`, `==`, `in`, `not in`, `is`, `is not` | сравнения |
| 12 | `not` | логическое НЕ |
| 13 | `and` | логическое И |
| 14 | `or` | логическое ИЛИ |
| 15 | `x if condition else y` | условное выражение |
| 16 | `lambda` | анонимная функция |
| 17 | `:=` | выражение присваивания |

Скобки позволяют явно изменить порядок:

```python
print(2 + 3 * 4)    # 14
print((2 + 3) * 4)  # 20
```

Оператор `**` связывается справа налево:

```python
print(2 ** 3 ** 2)    # 512, то же самое, что 2 ** (3 ** 2)
print((2 ** 3) ** 2)  # 64
```

## Что не является оператором {#chto-ne-yavlyaetsya-operatorom}

Не всякое специальное слово или знак в Python является оператором:

| Синтаксис | Что это |
| --- | --- |
| `if`, `for`, `while`, `def`, `class` | ключевые слова, начинающие инструкции |
| `return`, `break`, `continue`, `pass` | простые инструкции |
| `import`, `from` | инструкции импорта |
| `del` | инструкция удаления |
| `:` после `if`, `for`, `def` | часть синтаксиса блока |
| `,` | разделитель и часть синтаксиса кортежа |
| `#` | начало комментария |
