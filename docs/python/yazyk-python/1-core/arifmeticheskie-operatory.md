## Что это за операторы

Арифметические операторы нужны для вычислений с числами:

| Оператор | Значение | Пример |
| --- | --- | --- |
| `+` | сложение | `2 + 3` |
| `-` | вычитание | `5 - 2` |
| `*` | умножение | `4 * 3` |
| `/` | деление | `7 / 2` |
| `**` | возведение в степень | `2 ** 3` |
| `//` | целочисленное деление | `7 // 2` |
| `%` | остаток от деления | `7 % 2` |

## Базовые примеры

```python
print(2 + 3)   # 5
print(5 - 2)   # 3
print(4 * 3)   # 12
print(7 / 2)   # 3.5
print(2 ** 3)  # 8
print(7 // 2)  # 3
print(7 % 2)   # 1
```

## Ограничения чисел

В Python у `int` и `float` разные ограничения.

`int` не ограничен фиксированным `int32` или `int64`. Целое число может быть очень большим, пока хватает памяти.

```python
big_number = 10 ** 100

print(big_number)
```

Это удобно для точных целочисленных вычислений, но большие числа все равно требуют больше памяти и времени на операции.

`float` ограничен точностью. Он хранит число в двоичном формате, поэтому часть десятичных дробей представляется неточно.

```python
print(0.1 + 0.2)  # 0.30000000000000004
print(0.1 + 0.2 == 0.3)  # False
```

Для сравнения `float` часто используют допуск.

```python
from math import isclose

print(isclose(0.1 + 0.2, 0.3))  # True
```

Если нужна точная десятичная арифметика, например для денег, используй `Decimal`.

```python
from decimal import Decimal

total = Decimal("0.1") + Decimal("0.2")

print(total)  # 0.3
```

Есть и специальные значения:

```python
print(float("inf"))
print(float("-inf"))
print(float("nan"))
```

Важная практическая деталь для ML/data: в NumPy и Pandas часто используются фиксированные типы вроде `int64`, `float32`, `float64`. У них уже есть жесткие границы и возможны переполнение или потеря точности. Это отличается от обычного Python `int`.

Практическое правило:

- для счетчиков, id и точных целых значений используй `int`;
- для ML-скорингов, вероятностей и метрик обычно подходит `float`;
- для денег и точной десятичной арифметики используй `Decimal`;
- для сравнения `float` не полагайся на точное `==`, если результат получен вычислениями.

## Деление: `/` и `//`

`/` всегда возвращает результат обычного деления.

```python
print(8 / 2)  # 4.0
print(7 / 2)  # 3.5
```

Даже если число делится без остатка, результат будет `float`.

`//` возвращает результат деления без дробной части, но важно: это округление вниз, а не просто "отрезать хвост".

```python
print(7 // 2)    # 3
print(-7 // 2)   # -4
```

Для положительных чисел `//` выглядит как "целая часть". Для отрицательных результат уходит вниз по числовой прямой.

## Остаток от деления: `%`

`%` возвращает остаток от деления.

```python
print(7 % 2)   # 1
print(10 % 5)  # 0
```

Частые сценарии:

- проверить четность;
- разложить элементы по группам;
- сделать циклический индекс.

```python
number = 8

if number % 2 == 0:
    print("even")
```

Циклический индекс:

```python
items = ["train", "valid", "test"]

for index in range(5):
    print(items[index % len(items)])
```

## Практическая задача: подъезд и этаж

В высотном доме `5` подъездов, в каждом подъезде по `20` квартир. На каждом этаже `4` квартиры.

Нумерация квартир идет подряд снизу вверх:

- на `1` этаже `1` подъезда находятся квартиры `1`, `2`, `3`, `4`;
- на `2` этаже `1` подъезда находятся квартиры `5`, `6`, `7`, `8`;
- после квартиры `20` начинается `2` подъезд.

Напиши функцию `get_entrance_and_floor(flat_number)`, которая получает номер квартиры и возвращает номер подъезда и этажа.

Проверь функцию на разных значениях:

```python
print(get_entrance_and_floor(1))
print(get_entrance_and_floor(4))
print(get_entrance_and_floor(5))
print(get_entrance_and_floor(20))
print(get_entrance_and_floor(21))
```

Подумай, где здесь нужны:

- `//` - чтобы получить номер группы;
- `%` - чтобы найти позицию квартиры внутри подъезда;
- `flat_number - 1` - чтобы перейти от человеческой нумерации к индексу с нуля.

::: details Решение

```python
def get_entrance_and_floor(flat_number: int) -> str:
    # На каждом этаже 4 квартиры: 1-4, 5-8, 9-12 и так далее.
    apartments_per_floor = 4

    # В одном подъезде 20 квартир. После каждой группы из 20 квартир начинается новый подъезд.
    apartments_per_entrance = 20

    # Переводим номер квартиры в индекс с нуля.
    # Так квартира 1 станет индексом 0, а квартира 20 - индексом 19.
    # Это удобно для деления на группы через // и %.
    index = flat_number - 1

    # Целочисленное деление показывает, сколько полных подъездов прошло до этой квартиры.
    # +1 нужен, потому что подъезды считаются с 1, а не с 0.
    entrance = index // apartments_per_entrance + 1

    # Остаток от деления показывает позицию квартиры внутри своего подъезда.
    # Потом делим эту позицию на 4 квартиры на этаже.
    # +1 нужен, потому что этажи тоже считаются с 1.
    floor = index % apartments_per_entrance // apartments_per_floor + 1

    # Возвращаем готовый текст, чтобы результат было удобно вывести через print().
    return f"Подъезд: {entrance}, этаж: {floor}"


print(get_entrance_and_floor(10))
```

Если `flat_number = 10`, то `index = 9`.

```python
entrance = 9 // 20 + 1       # 1
floor = 9 % 20 // 4 + 1      # 3
```

Ответ: `1` подъезд, `3` этаж.

:::

## Степень: `**`

`**` возводит число в степень.

```python
print(2 ** 3)    # 8
print(9 ** 0.5)  # 3.0
```

В ML и data-коде степень часто встречается в формулах ошибок, расстояний и нормировок.

```python
error = prediction - target
squared_error = error ** 2
```

## Приоритет операций

Python считает выражения по приоритету операторов:

1. скобки;
2. степень `**`;
3. умножение, деление, `//`, `%`;
4. сложение и вычитание.

```python
print(2 + 3 * 4)    # 14
print((2 + 3) * 4)  # 20
```

Практическое правило: если выражение не читается сразу, ставь скобки.

## Типичные ошибки

1. Ожидать от `/` целое число.
   Проблема: `/` возвращает `float`.
   Решение: если нужно целочисленное деление, используй `//`.

2. Считать `//` простым отбрасыванием дробной части.
   Проблема: для отрицательных чисел `-7 // 2 == -4`.
   Решение: помнить, что `//` округляет вниз.

3. Путать `**` и `^`.
   Проблема: `^` в Python - побитовое XOR, а не степень.
   Решение: для степени использовать `**`.

4. Делить на ноль.
   Проблема: `ZeroDivisionError`.
   Решение: проверять делитель до операции.

5. Забывать про приоритет операций.
   Проблема: выражение считается не так, как ожидалось.
   Решение: использовать скобки для явного порядка.

6. Сравнивать `float` через точное `==` после вычислений.
   Проблема: двоичное представление дробей дает неожиданные хвосты.
   Решение: использовать `math.isclose()` или сравнение с допуском.

## Cheat-sheet

| Задача | Оператор |
| --- | --- |
| Сложить | `a + b` |
| Вычесть | `a - b` |
| Умножить | `a * b` |
| Поделить | `a / b` |
| Получить целую часть деления | `a // b` |
| Получить остаток | `a % b` |
| Возвести в степень | `a ** b` |
| Проверить четность | `value % 2 == 0` |
| Сравнить `float` с допуском | `isclose(a, b)` |
| Точная десятичная арифметика | `Decimal("0.1")` |
