## Что изучаем {#chto-izuchaem}

Метакласс — это объект, который создаёт классы. Это звучит непривычно, потому что обычно мы рассматриваем класс как готовое описание будущих объектов.

Начнём с уже знакомой цепочки:

```python
class User:
    pass


user = User()

print(type(user) is User)  # True
print(type(User) is type)  # True
```

`User` создаёт экземпляр `user`, а стандартный метакласс `type` создаёт класс `User`.

```text
type  → создаёт класс User → класс User создаёт объект user
```

Главная идея раздела: класс в Python тоже является объектом. Поэтому у класса тоже есть объект, который отвечает за его создание.

## Когда это пригодится {#kogda-eto-prigoditsya}

Метакласс может выполнить действие в момент объявления класса:

- проверить обязательные атрибуты;
- добавить классу новый атрибут или метод;
- автоматически зарегистрировать дочерний класс;
- изменить способ создания экземпляров;
- подготовить специальное пространство имён для тела класса.

Такие механизмы встречаются в ORM, фреймворках, системах плагинов и сложных библиотеках. В обычном прикладном коде метаклассы нужны редко.

Перед этим разделом полезно понимать:

- разницу между [классом и экземпляром](../klass-i-ekzemplyar.md);
- назначение [`__init__`, `self` и атрибутов](../init-self-atributy-i-metody.md);

- назначение `__new__` на базовом уровне;

Метаклассы относятся к продвинутому Python. Если отдельный фрагмент пока не понятен, сначала достаточно усвоить цепочку `type → класс → экземпляр`.

## Словарь раздела {#slovar-razdela}

| Термин | Простое объяснение |
| --- | --- |
| Экземпляр | конкретный объект, созданный классом |
| Класс | объект, который описывает и создаёт экземпляры |
| Метакласс | объект, который создаёт классы |
| `type` | стандартный метакласс Python |
| Пространство имён | словарь с атрибутами и методами будущего класса |
| `metaclass=` | способ явно назначить метакласс |
| Реестр | словарь или другая коллекция созданных классов |

## Как изучать раздел {#kak-izuchat-razdel}

Для каждой страницы:

1. выполни минимальный пример;
2. добавь один `print(type(...))` и предскажи результат;
3. измени один атрибут или условие;
4. объясни, какой объект создаёт метакласс, а какой — обычный класс;
5. только после этого переходи к следующей странице.

Не пытайся сразу запомнить все специальные методы. Важнее понимать момент, в который каждый из них выполняется.

## Краткий результат раздела {#kratkiy-rezultat-razdela}

После изучения ты должен уметь:

- объяснить разницу между классом и метаклассом;
- прочитать простую реализацию `class Meta(type)`;
- понять аргументы `name`, `bases` и `namespace`;
- создать проверку класса через `__new__`;
- объяснить, почему иногда лучше использовать `__init_subclass__()`;
- распознать конфликт метаклассов.
